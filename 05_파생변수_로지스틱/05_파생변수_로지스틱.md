# 1. 🎯 분석 목적

EDA 단계에서는 9개 제품 속성 모두 만족도(`Y`)와 통계적으로 유의한 관계가 확인되어 **모든 속성을 1차 후보 변수로 유지**하였다.

하지만 이변량 분석은 각 속성과 `Y`를 **1:1로 비교한 전체 평균적 관계**이므로 다음 질문까지는 설명할 수 없다.

> **“다른 속성과 국가를 함께 고려했을 때도 같은 효과가 유지되는가?”**
> 

또한 국가별 표본에서 만족도 분포 차이가 관찰되었기 때문에 다음 질문도 추가로 확인할 필요가 있었다.

> **“같은 속성이라도 국가에 따라 만족도에 미치는 영향이 달라지는가?”**
> 

이에 따라 분석을 다음과 같이 확장하였다.

```
EDA
↓
9개 속성의 전체적인 연관성 확인
↓
국가 × 속성 상호작용 파생변수 생성
↓
다중 로지스틱 회귀
국가 + 속성
국가 + 속성 + 국가 × 속성 모델 각각 돌려 비교
↓
국가별 조건부 효과(국가x속성) 검증
```

## 제외 근거

9개 속성이 모두 0인 리뷰는 현재 정의된 속성 체계에서 어떤 제품 요인이 언급되었는지 확인할 수 없으므로,

속성 기반 효과 분석에서는 설명할 정보가 없는 관측치로 판단하여 제외하였다.

# 3. 🎯 종속변수 및 분석 방법 선택

종속변수는 `Y`를 사용하였다.

```
Y = 1 → 별점 4·5점 = 만족
Y = 0 → 별점 1·2점 = 불만족
```

별점 3점 리뷰는 이전 전처리 단계에서 제외된 상태이다.

## 왜 이항 로지스틱 회귀를 사용했는가?

`Y`가 만족/불만족의 **이진 범주형 변수**이므로, 연속형 값을 예측하는 선형회귀보다

두 범주의 발생 확률을 분석하는 **이항 로지스틱 회귀가 적합**하다.

로지스틱 회귀를 사용하면

- 각 속성이 만족 리뷰일 오즈(Odds)를 얼마나 높이거나 낮추는지 해석할 수 있고
- 국가×속성 상호작용을 통해 **국가별 효과 차이**도 동시에 검증할 수 있다.

# 4. 🚫 모델에서 제외한 변수와 근거

## 4.1 `리뷰_번호` 제외

`리뷰_번호`는 각 리뷰를 식별하기 위한 고유 ID일 뿐, 소비자의 만족도를 설명하는 제품 특성이 아니다.

따라서 설명변수로 사용하지 않았다.

---

## 4.2 `별점` 제외 — 데이터 누수 방지

`Y`는 원래 별점으로부터 생성된 변수이다.

```
별점 1·2 → Y = 0
별점 4·5 → Y = 1
```

따라서 별점을 다시 독립변수에 포함하면 모델이 사실상 정답을 직접 이용하게 되는

- Data Leakage(데이터 누수)가 발생한다.

이에 회귀분석에서는 `Y`만 종속변수로 사용하고 원본 `별점`은 설명변수에서 제외하였다.

---

## 4.3 `제품_순위` 제외

EDA 이변량 분석에서는 `제품_순위`와 만족도 사이에 통계적으로 유의한 관계가 확인되었다.

```
χ² = 65.48
p < .001
Cramer's V = 0.099
```

그러나 로지스틱 회귀에서는 다음 근거로 제외하였다.

### ① 효과크기가 작음

`Cramer's V = 0.099`로 관계의 크기는 **Negligible** 수준이었다.

즉 통계적 연관성은 존재하지만, 제품순위만으로 만족도를 강하게 설명한다고 보기 어렵다.

### ② 순위 증가에 따른 일관된 패턴이 없음

제품별 만족률은

- 7위: **76.7%** — 가장 높음
- 8위: **58.0%** — 가장 낮음

으로 나타났지만, 1위에서 10위로 갈수록 만족률이 일정하게 증가하거나 감소하지 않았다.

따라서 `1, 2, 3 ... 10`을 숫자 그대로 넣어

> **“순위가 1 증가할 때 만족도가 일정하게 변한다”**
> 

라고 해석할 근거가 부족하다.

### ③ 동일 순위라도 국가별로 서로 다른 제품임

```
한국 1위 ≠ 미국 1위 ≠ 일본 1위 ≠ 러시아 1위
```

즉 `제품_순위=1`이 하나의 동일한 제품 특성을 의미하지 않는다.

국가별 서로 다른 제품을 같은 순위 숫자로 묶으면 회귀계수의 의미가 불명확해질 수 있다.

### ④ 이번 로지스틱 분석의 연구질문과 직접적인 관련이 낮음

이번 분석의 핵심은

> **“제품의 순위가 만족도에 미치는 영향”**
> 

이 아니라,

> **“각 제품 속성이 만족도에 미치는 영향이 국가별로 어떻게 달라지는가”**
> 

이다.

따라서 해석의 초점을 명확히 하기 위해 `제품_순위`를 로지스틱 회귀에서는 제외하였다.

> **결론:** 제품순위는 EDA에서는 참고 변수로 확인하되,
> 
> 
> 국가별 속성 효과를 설명하는 로지스틱 회귀에서는 제외하였다.
> 

※ 이후 머신러닝 단계에서는 제품 자체의 차이를 통제하기 위해 

`국가 + 제품순위`를 결합한 `제품_ID`를 명목형 변수로 별도 활용한다.

# 5. ✅ 9개 속성을 모두 유지한 이유

EDA 카이제곱 검정에서는 **9개 속성 모두 `Y`와 통계적으로 유의한 관계**가 확인되었다.

일부 속성은 Cramer's V가 작아 단독 설명력이 제한적으로 보였지만, 이를 이유로 EDA 단계에서 제거하지 않았다.

## 근거

### ① EDA 효과크기는 전체 표본에서의 평균적 관계

이변량 분석은 국가를 구분하지 않고 전체 데이터를 한 번에 본 결과이다.

따라서 전체에서는 약하게 보이는 속성도 특정 국가에서는 더 강하게 나타나거나 반대 방향을 보일 가능성이 있다.

### ② 프로젝트의 핵심 질문이 국가별 차이임

이번 프로젝트는 전체 소비자의 공통적인 만족 요인만 찾는 것이 아니라,

> **국가별 소비자 선호 구조의 차이**
> 

를 확인하는 것이 핵심 목적이다.

따라서 전체 효과가 작은 속성이라도 국가별로 달라질 가능성이 있다면 분석에서 유지할 필요가 있다.

### ③ 실제 상호작용 분석에서도 국**가별 차이가 확인됨**

후속 로지스틱 회귀에서는 전체 효과만 보면 약하거나 유의하지 않은 속성도 특정 국가에서 의미 있게 나타났다.

예:

- `향` → 러시아에서 유의
- `기능` → 미국에서 유의
- `가격` → 일본에서 유의
- `브랜드충성도` → 국가별 방향 자체가 다름

따라서

> **“EDA에서 효과크기가 작다 = 제거”**
> 

로 판단하지 않고, 9개 속성을 모두 유지하여 국가별 조건부 효과를 검증하였다.

# 6. 🇰🇷 한국을 기준 국가로 설정한 이유

## 6.1 프로젝트의 출발점이 K-Beauty이기 때문

본 프로젝트는 **글로벌 리뷰 데이터를 활용해 스킨케어 크림 선호 요인을 분석하고, 결과를 K-Beauty 해외 현지화 전략으로 연결하는 것**을 목적으로 한다.

한국은 K-Beauty의 본국이며, 프로젝트 서론에서도 K-Beauty의 글로벌 성장과 기초화장품의 중요성을 분석 배경으로 설정하였다.

따라서 연구 질문 역시 단순히

> “어느 국가가 더 만족하는가?”
> 

가 아니라,

> **“한국 소비자와 비교했을 때 해외 소비자는 어떤 속성에 다르게 반응하는가?”**
> 

라는 구조로 설정하는 것이 프로젝트 목적과 자연스럽게 연결된다.

---

## 6.2 한국을 Benchmark로 사용하면 해석이 직관적임

한국을 기준으로 설정하면 다음과 같이 해석할 수 있다.

```
한국에서의 속성 효과
        ↓ 비교
미국에서는 얼마나 다른가?
일본에서는 얼마나 다른가?
러시아에서는 얼마나 다른가?
```

즉 K-Beauty 본국 소비자의 반응을 기준점으로 두고, 해외 시장에서 강화되거나 약화되는 속성을 직접 비교할 수 있다.

> **한국 시장을 출발점으로 해외 시장의 차이를 측정한다는 스토리라인을 유지하기 위해 한국을 기준 국가로 설정하였다.**
> 

---

## 6.3 통계적으로 한국이 더 우수하다는 의미는 아님

기준범주는 회귀계수의 **해석 기준점**이다.

한국 대신 미국·일본·러시아를 기준으로 바꾸더라도 데이터 구조 자체나

상호작용 전체가 존재하는지에 대한 결론이 달라지는 것은 아니다.

달라지는 것은 **개별 회귀계수를 어느 국가와 비교해서 해석하는가**이다.

따라서 본 프로젝트에서는 통계적 우열이 아니라

**연구 목적과 해석의 일관성**을 기준으로 한국을 기준 국가로 선택하였다.

# 7. ⚙️ 국가 더미 변수 생성

국가는 범주형 변수이므로 회귀분석에서 사용할 수 있도록 0/1 형태의 더미 변수로 변환하였다.

한국을 기준 국가로 두었기 때문에 다음 3개의 국가 더미만 생성하였다.

| 국가 | `국가_러시아` | `국가_미국` | `국가_일본` |
| --- | --- | --- | --- |
| **한국** | 0 | 0 | 0 |
| 러시아 | 1 | 0 | 0 |
| 미국 | 0 | 1 | 0 |
| 일본 | 0 | 0 | 1 |

즉,

> **세 국가 더미가 모두 0이면 한국**
> 

을 의미한다.

한국 더미를 별도로 만들지 않은 이유는 한국을 기준범주로 두고 나머지 국가와의 차이를 비교하기 위함이다.

# 8. 🧩 국가 × 속성 상호작용 파생변수 생성

9개 속성은 모두 다음과 같은 이진 변수이다.

```
0 = 해당 속성 미언급
1 = 해당 속성 언급
```

각 국가 더미와 9개 속성을 곱하여 상호작용항을 생성하였다.

예:

```
국가_미국_x_보습 = 국가_미국 × 보습
```

## 생성 예시

| 국가 | 국가_미국 | 보습 | 국가_미국_x_보습 | 의미 |
| --- | --- | --- | --- | --- |
| 한국 | 0 | 1 | 0 | 한국에서 보습 언급 |
| 미국 | 1 | 0 | 0 | 미국이지만 보습 미언급 |
| 미국 | 1 | 1 | **1** | **미국에서 보습 언급** |
| 일본 | 0 | 1 | 0 | 일본에서 보습 언급 |

따라서 `국가_미국_x_보습 = 1`은 단순히 미국 리뷰라는 뜻이 아니라,

> **“미국 리뷰이면서 동시에 보습 속성이 언급된 경우”**
> 

를 의미한다.

### 해석

`p < .001`이므로 27개의 국가×속성 상호작용을 추가했을 때

모형 적합도가 통계적으로 유의하게 개선되었다.

> **제품 속성과 만족도의 관계가 분석 대상 국가별 표본에서 동일하게 나타나지 않는다.**

Pseudo R² 역시

```
0.172 → 0.192
```

> LRT는 “상호작용 블록 전체가 필요한가?”를 검정한다.
> 
> 
> 어느 속성이 어느 국가에서 다른지는 개별 상호작용 계수를 추가로 확인해야 한다.

# 15. 📊 국가별 실제 효과 — Odds Ratio

상호작용 계수는 **한국과의 차이**를 보여준다.

따라서 각 국가에서 해당 속성이 만족도와 실제로 어떤 관계를 가지는지 확인하기 위해

**주효과 + 해당 국가의 상호작용 효과**를 합산한 뒤 Odds Ratio(OR)로 변환하였다.

```
OR > 1 → 해당 속성 언급 시 만족 오즈 증가
OR < 1 → 해당 속성 언급 시 만족 오즈 감소
OR ≈ 1 → 뚜렷한 변화 없음
```

- * = p < .05

`n.s.` = 통계적으로 유의하지 않음

- 각 국가 OR의 유의성은 속성 주효과와 국가×속성 계수를 더한 선형결합의 **Wald 검정(`result.t_test()`)**으로 산출하였다.
- 15절의 표는 **해당 국가에서 OR≠1이 유의함**을 의미하며, 14절의 상호작용 유의성(한국과의 효과 차이)과는 다른 가설을 검정하므로 두 결과는 서로 다를 수 있다.

# 16. ❓ EDA에서는 유의했는데 로지스틱에서는 왜 달라지는가?

EDA의 카이제곱 검정과 다중 로지스틱 회귀는 **서로 다른 질문**을 검정한다.

| 분석 | 질문 |
| --- | --- |
| 카이제곱 | 이 속성과 만족도는 **전체적으로 관련이 있는가?** |
| 주효과 로지스틱 | 다른 국가·속성을 함께 고려해도 **독립적인 관계가 남는가?** |
| 상호작용 로지스틱 | **그 관계가 국가에 따라 달라지는가?** |

따라서 EDA에서 유의했던 변수가 로지스틱에서 비유의하게 바뀌는 것은 모순이 아니다.

다른 변수와 국가를 동시에 고려하면서 처음에 보였던 관계가 다른 요인과 공유되거나,

국가별 효과로 분해되기 때문이다.

또한 한국을 기준으로 상호작용을 넣은 모형에서

`보습`, `향`, `기능` 등의 **주효과는 전체 국가의 평균 효과가 아니라 한국에서의 효과**를 의미한다.

따라서

> **주효과가 비유의 = 해당 속성이 모든 국가에서 중요하지 않음**
> 

으로 해석하면 안 된다.

이번 최신 결과에서는 `기능`의 한국 효과도 유의하며(`OR=2.13*`), 미국에서도 `OR=2.85*`로 유의한 긍정 효과가 확인되었다.

다만 `미국×기능` 상호작용 자체는 `p=.088`로 유의하지 않으므로,

> **미국에서 기능 효과가 유의하다**는 사실과
> 
> 
> **미국의 기능 효과가 한국보다 유의하게 더 크다**는 주장은 서로 다른 의미이다.
> 

반대로 일본·러시아의 기능 상호작용은 한국 대비 유의하게 음(-)의 방향으로 나타났지만, 해당 국가 내 실제 기능 OR은 각각 유의하지 않았다.

# 17. ✅ 로지스틱에서 비유의한 변수도 제거하지 않은 이유

상호작용 모형에서는 **주효과와 상호작용항의 계층 구조(Hierarchy)**를 유지해야 해석이 가능하다.

예를 들어

```
기능
+
국가_미국_x_기능
```

에서 미국의 기능 효과는

```
기능 주효과 + 미국×기능 상호작용
```

으로 계산된다.

따라서 한국에서의 `기능` 주효과가 비유의하다는 이유로 원속성을 제거하면

미국×기능 상호작용의 기준이 사라져 해석 구조가 깨진다.

또한 LRT에서 상호작용 27개 **전체 블록이 유의**했으므로,

개별 p-value만 보고 상호작용항을 하나씩 사전에 제거하지 않았다.

> **개별 비유의 = 효과가 없다는 증명**이 아니다.
> 
> 
> 본 분석에서는 **현재 데이터에서 독립적인 효과를 통계적으로 확인하지 못했다**는 의미로 해석한다.
>

# 19. ⚠️ 해석 시 주의사항

- 본 분석은 **상관관계 기반 로지스틱 회귀**이므로 인과관계를 증명하지 않는다.
- 상호작용 모형은 변수 수가 많아 일부 국가×속성 조합의 표본이 적을 수 있다.
- 특히 배송·가격 등 언급 비율이 낮은 속성은 추정의 불확실성이 상대적으로 클 수 있다.
- `p > .05`는 “효과가 없다”가 아니라 **이 데이터에서 유의한 효과를 확인하지 못했다**고 표현하는 것이 적절하다.
- 리뷰는 평점 높은 순·평점 낮은 순 중심으로 구성된 분석 표본이므로 실제 시장 전체의 자연적인 별점 분포를 그대로 대표하지 않는다.
- 본 분석의 목적은 인과 추정이 아니라 **국가별 소비자 만족·불만족과 연결되는 속성 구조를 설명하는 것**이다.
- 4개국 리뷰는 **번역**(미국 EN→KR, 일본·러시아 원어→EN→KR)을 거쳐 사전과 매칭되었다.
    - 국가 간 OR 크기 차이에는 **번역 어휘 차이가 혼입**되므로 국가 내 속성 간 순위 비교가 국가 간 절대값 비교보다 안전하다.
    - 번역 영향은 한 나라 안에서 속성끼리 순위를 비교할 때 상당 부분 상쇄되므로, **국가 내 비교**를 우선하는 방침을 세웠다.

### ⚠️ 국가별 제품 구성 차이에 따른 해석 한계

본 분석은 국가별로 서로 다른 상위 제품을 대상으로 리뷰를 수집하였기 때문에, 동일 제품에 대한 국가별 소비자 반응을 직접 비교한 구조는 아니다. 따라서 국가별 차이에는 소비자 특성뿐 아니라 **국가별 제품 구성 차이의 영향이 함께 포함될 수 있으며**, 국가×속성 상호작용을 순수한 국가 또는 문화적 효과로 단정하지 않는다. 본 결과는 **각 국가에서 선정된 제품군 내에서 나타난 속성별 만족도 관계의 차이**로 해석한다.

# ✅ 최종 결론

EDA에서는 9개 제품 속성이 모두 만족도와 유의한 관계를 보여 후보 변수로 유지하였다.

다만 단순 이변량 분석만으로는 국가에 따라 달라지는 속성 효과를 설명하기 어렵기 때문에,

본 프로젝트의 K-Beauty 글로벌 전략이라는 목적에 맞춰 **한국을 기준 시장으로 설정하고 국가×속성 상호작용 파생변수 27개를 생성**하였다.

제품_순위는 이변량 단계에서는 유의했지만, **효과크기가 작고 순위에 따른 일관된 패턴이 없으며 국가마다 동일 순위가 서로 다른 제품을 의미**하므로 로지스틱 해석 변수에서는 제외하였다.

이후 주효과 모형과 상호작용 모형을 LRT로 비교한 결과,

`LR χ²=175.15`, `df=27`, `p<.001`로 상호작용을 추가한 모형이 유의하게 개선되었다.

따라서 본 분석에서는

> **“제품 속성과 만족도의 관계는 분석 대상 국가별 표본에서 동일하게 나타나지 않는다.”**
> 

는 결론을 도출하였으며, 이후 머신러닝 단계에서는 통계적 유의성과는 별도로

각 변수의 **예측 기여도와 일반화 성능**을 추가적으로 검증한다.
