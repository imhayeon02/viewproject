# 🧴 CreamyView

### 글로벌 K-Beauty 스킨케어 리뷰 데이터 분석 프로젝트

**리뷰 속 소비자는 무엇을 말하고, 분석가는 무엇을 들어야 하는가?**

한국·미국·일본·러시아 **4개국 온라인 쇼핑몰의 스킨케어 크림 리뷰**를 수집하고, 텍스트마이닝·통계분석·머신러닝을 활용해 **국가별 만족·불만족 요인**을 파악한 뒤 **K-Beauty 현지화 전략**을 제안한 팀 프로젝트입니다.

> **프로젝트 핵심:** 불만족 신호는 여러 국가에서 공통으로 나타났지만, 만족과 연관된 제품 속성의 중요도는 국가에 따라 달랐습니다.

| 구분 | 내용 |
|:--|:--|
| 프로젝트 | CreamyView — K-Beauty 리뷰 데이터 분석 |
| 수행 연도 | 2026년 |
| 팀원 | 김지수 · 복헌영 · 손새연 · 임하연 |
| 분석 국가 | 🇰🇷 한국 · 🇺🇸 미국 · 🇯🇵 일본 · 🇷🇺 러시아 |
| 수집 플랫폼 | Olive Young · Ulta · Rakuten · Wildberries |
| 분석 대상 | 4개국, 국가별 인기 스킨케어 크림 10개 제품(총 40개 제품) |
| 주요 방법 | 웹 크롤링 · 텍스트마이닝 · EDA · 로지스틱 회귀 · 머신러닝 · SHAP |

## 1. 프로젝트 배경과 목표

K-Beauty가 글로벌 시장으로 확장되면서 소비자들은 **보습, 향, 발림성, 피부 자극, 기능, 가격** 등 서로 다른 기준으로 스킨케어 제품을 평가합니다. 별점만으로는 만족·불만족의 **구체적인 이유**와 **국가별 차이**를 파악하기 어렵습니다.

이 프로젝트는 다음 질문에 답하고자 했습니다.

1. 국가별 스킨케어 크림 리뷰에는 어떤 표현과 관심 요소가 자주 나타나는가?
2. 리뷰 텍스트를 제품의 주요 속성으로 구조화할 수 있는가?
3. 각 속성의 언급 여부는 만족·불만족과 어떤 관계를 보이는가?
4. 동일한 속성과 만족도의 관계가 국가에 따라 달라지는가?
5. 머신러닝은 만족·불만족을 예측할 때 어떤 속성을 중요하게 활용하는가?
6. 이러한 결과를 K-Beauty의 해외 현지화 전략에 어떻게 활용할 수 있는가?

## 2. 데이터 수집

**수집 기간:** 2026.04.24 ~ 2026.04.28

| 국가 | 온라인 플랫폼 | 수집 설계 |
|:--:|:--|:--|
| 🇰🇷 한국 | Olive Young | 상위 10개 제품 × 제품당 리뷰 200건 |
| 🇺🇸 미국 | Ulta | 상위 10개 제품 × 제품당 리뷰 200건 |
| 🇯🇵 일본 | Rakuten | 상위 10개 제품 × 제품당 리뷰 200건 |
| 🇷🇺 러시아 | Wildberries | 상위 10개 제품 × 제품당 리뷰 200건 |

- **수집 방식:** Selenium으로 동적 페이지 및 정렬을 처리하고, BeautifulSoup으로 제품·리뷰 데이터를 추출
- **리뷰 수집 기준:** 제품별 별점 높은 순 100건 + 낮은 순 100건을 목표로 수집
- **원본 데이터 구조:** 제품 순위, 리뷰 번호, 별점(1~5점), 리뷰 원문, 정렬 방식
- **원본 규모:** 총 **8,000건**(국가별 2,000건)

> ⚠️ 일본·러시아 플랫폼에서는 정렬 특성상 낮은 순 수집분에 4~5점 리뷰가 일부 포함되었습니다. 따라서 수집 데이터의 별점 분포를 각 국가 시장 전체의 실제 분포로 일반화하지 않았습니다.

## 3. 분석 과정

```text
4개국 리뷰 수집
      ↓
다국어 리뷰 번역 및 텍스트 정제
      ↓
Kiwi 형태소 분석 · TF-IDF 키워드 탐색
      ↓
9개 제품 속성 사전 기반 토픽 분류
      ↓
탐색적 데이터 분석(EDA)
      ↓
국가 × 제품 속성 파생변수 생성
      ↓
로지스틱 회귀 · 국가별 차이 검증
      ↓
머신러닝 모델 비교 · XGBoost 선정
      ↓
Feature Importance · SHAP · Group Holdout
      ↓
국가별 K-Beauty 현지화 전략 제안
```

### 3-1. 데이터 전처리 및 텍스트마이닝

- Google Sheets의 `GOOGLETRANSLATE`를 활용한 다국어 리뷰 번역
- 텍스트 정제 및 **Kiwi** 기반 형태소 분석
- **TF-IDF + 로지스틱 회귀**를 이용한 긍정·부정 연관 표현 탐색
- 3점 리뷰를 제외하고 **만족(4~5점)=1 / 불만족(1~2점)=0**으로 이진 분류
- 리뷰의 제품 속성 언급 여부를 **9개 속성별 0/1**로 라벨링(하나의 리뷰에 여러 속성 매칭 가능)

| 제품 속성 | 분석 내용 예시 |
|:--|:--|
| 보습 | 촉촉함, 수분 공급, 건조함 |
| 향 | 향기, 냄새, 무향 |
| 발림성 | 텍스처, 흡수력, 끈적임 |
| 자극 | 트러블, 자극, 피부 반응 |
| 용기 | 패키지, 디자인, 용량 |
| 배송 | 배송 속도, 파손, 누락 |
| 기능 | 효과, 탄력, 주름 개선 |
| 가격 | 가격, 가성비, 할인 |
| 브랜드충성도 | 재구매, 브랜드 신뢰, 시리즈 선호 |

**데이터 정리 흐름**

| 단계 | 데이터 수 |
|:--|--:|
| 원본 수집 | 8,000건 |
| 3점 리뷰 제외 후 | 7,230건 |
| 9개 속성 모두 미매칭인 리뷰 474건 제외 후 | **6,756건** |

### 3-2. EDA 및 통계 분석

- 국가별·속성별 리뷰 언급률과 만족 비율 분석
- 카이제곱 검정, **Cramér's V**를 통한 속성–만족도 연관성 점검
- 속성 간 상관관계와 중복 정보 확인
- **국가 × 속성 상호작용 변수 27개** 생성
- 로지스틱 회귀와 **우도비검정(LRT)**으로 국가별 속성 관계 차이 확인

### 3-3. 머신러닝 모델링 및 검증

- 데이터를 **Train 70% / Test 30%**로 계층화 분할
- Train 내부 **5-Fold Cross Validation**으로 모델 비교 및 하이퍼파라미터 탐색
- Logistic Regression, Random Forest, XGBoost, LightGBM, CatBoost 등 후보 모델 검토
- 최종 **XGBoost** 선정: F1뿐 아니라 ROC-AUC, 교차검증 변동성, 연산 효율을 종합 고려
- **Feature Importance · SHAP**으로 예측 기여도 해석
- 학습에서 보지 않은 제품을 대상으로 **Group Holdout 20회** 추가 검증

## 5. 주요 분석 결과

### 5-1. 불만족 요인은 공통, 만족 요인은 국가별 차이

- **자극:** 모든 국가에서 만족과 부정적 관계 (로지스틱 회귀 OR **0.28~0.45**)
- **배송:** 모든 국가에서 만족과 부정적 관계 (OR **0.21~0.45**)
- **보습:** 모든 국가에서 만족과 긍정적 관계 (OR **1.32~4.23**)
- 국가 × 속성 상호작용을 추가한 로지스틱 회귀 모형의 적합도가 개선됨 (**LR χ²=175.15, df=27, p<.001**)

### 5-2. 국가별 주요 만족 연관 속성

| 국가 | 주요 결과(유의한 OR) | 전략적 시사점 |
|:--|:--|:--|
| 🇰🇷 한국 | 기능 2.13 · 보습 1.32 · 발림성 1.28 | 기능과 사용감 강조 |
| 🇺🇸 미국 | 보습 4.23 · 기능 2.85 · 브랜드충성도 1.84 | 효능을 입증하는 고보습·저자극 메시지 |
| 🇯🇵 일본 | 브랜드충성도 2.58 · 보습 2.53 · 가격 1.83 | 브랜드 신뢰, 재구매 경험, 가성비 |
| 🇷🇺 러시아 | 향 2.32 · 브랜드충성도 2.15 · 보습 2.10 · 발림성 1.97 | 향과 텍스처를 통한 감각적 경험 강조 |

> OR(오즈비)는 해당 속성 언급과 만족 오즈의 통계적 **연관성**을 뜻하며, 인과관계를 입증하지 않습니다.

### 5-3. 최종 XGBoost 모델 성능

| 지표 | 최종 Test 결과 |
|:--|--:|
| Accuracy | **0.753** |
| F1 (만족) | **0.819** |
| F1 (불만족) | **0.614** |
| Macro-F1 | **0.716** |
| MCC | **0.438** |
| ROC-AUC | **0.813** |

- **Global SHAP:** 자극(20.8%), 제품_ID(16.1%), 기능(11.6%)이 주요 예측 기여 요인으로 확인됨
- **신규 제품 Group Holdout(20회 평균):** F1 **0.794**, MCC **0.370**, ROC-AUC **0.767**
- 메인 Test는 기존 40개 제품군 내 새로운 리뷰 예측 성능이며, Group Holdout은 학습에 포함되지 않은 제품에 대한 보조 검증 결과임

## 6. 결론 및 활용 방안

**공통적인 불만족 요인은 일관되게 관리하고, 만족 요인은 국가별 소비자 관심에 맞게 차별화하는 전략이 필요합니다.**

- **공통 관리:** 피부 자극 최소화, 배송·포장 품질 개선, 기본 보습력 확보
- **미국:** 보습력과 제품 효과를 구체적으로 검증·소구
- **일본:** 저자극·보습을 바탕으로 브랜드 신뢰와 재구매 혜택 강화
- **러시아:** 향, 발림성, 텍스처 중심의 제품 경험 차별화

### 분석의 한계

- 각 국가에서 1개 플랫폼, 인기 제품 10개만 분석했으므로 전체 시장으로 일반화하기 어려움
- 별점 높은 순·낮은 순으로 수집한 표본이므로 실제 별점 분포를 반영하지 않음
- 국가별 플랫폼·제품 구성이 달라 국가 효과와 플랫폼·제품 효과를 완전히 분리하기 어려움
- 번역 및 키워드 사전 기반 토픽 분류에 따른 뉘앙스 손실이나 분류 오차 가능성
- 통계적 연관성과 예측 기여도는 인과적 영향의 증거가 아님
