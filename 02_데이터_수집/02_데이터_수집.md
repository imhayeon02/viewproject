## 1. 🎯 목표

한국·미국·일본·러시아의 대표 온라인 쇼핑 플랫폼에서 **스킨케어 크림 제품의 소비자 리뷰를 동일한 기준으로 수집**한다.

국가별 플랫폼의 화면 구성과 카테고리 이동 경로는 서로 다르지만, 최종 분석 대상의 조건은 동일하게 맞췄다.

- 국가별 **크림 인기순 상위 10개 제품**
- 제품별 **고평점 리뷰 100건**
- 제품별 **저평점 리뷰 100건**
- 제품당 총 **200건**
- 국가별 총 **2,000건**
- 4개국 총 **8,000건**

이를 통해 국가별 리뷰 수의 차이를 최소화하고, 이후 만족·불만족 및 제품 속성 비교에 활용할 수 있는 원천 데이터를 구축하였다.

## 3. ⚙️ 공통 수집 기준

4개국 모두 동일한 분석 조건을 적용하였다.

### 3.1 제품 선정 기준

- 국가별 플랫폼의 **스킨케어 크림 관련 카테고리**에서 제품 확인
- 상위 노출·인기 제품을 기준으로 **국가별 10개 제품** 선정
- 국가마다 동일한 제품 수를 사용하여 국가 간 표본 규모 차이를 줄임

### 3.2 리뷰 수집 기준

각 제품에서 다음 기준으로 리뷰를 수집하였다.

- **평점 높은 순 리뷰 100건**
- **평점 낮은 순 리뷰 100건**
- 제품당 총 **200건**

따라서 국가별 수집 목표는 다음과 같다.

```
제품 10개
×
제품당 리뷰 200건
=
국가별 리뷰 2,000건
```

4개국 전체 기준으로는 총 **8,000건**의 원본 리뷰를 확보하였다.

### 3.3 수집 도구

플랫폼별 웹 구조에 대응하기 위해 다음 도구를 함께 사용하였다.

- **Selenium**: 페이지 이동, 정렬 조건 변경, 스크롤, 동적 로딩 처리
- **BeautifulSoup**: HTML 파싱 및 리뷰 텍스트·별점 등 필요한 정보 추출

플랫폼마다 버튼명과 리뷰 영역 구조는 다르지만, 수집 원칙과 최종 데이터 구조는 동일하게 유지하였다.

## 5. 🧱 수집 데이터 구성

4개국 모두 크롤링 결과를 동일한 5개 컬럼으로 정리하였다.

| 컬럼명 | 설명 |
| --- | --- |
| `제품_순위` | 국가별로 선정한 10개 제품의 순위 |
| `리뷰_번호` | 각 리뷰를 구분하기 위한 리뷰 번호 |
| `별점` | 소비자가 부여한 원래 별점 |
| `리뷰_원문` | 플랫폼에서 수집한 번역 전 원문 리뷰 |
| `정렬방식` | 고평점/저평점 중 어떤 기준으로 수집된 리뷰인지 구분 |

### 5.1 데이터 구조 예시

| 제품_순위 | 리뷰_번호 | 별점 | 리뷰_원문 | 정렬방식 |
| --- | --- | --- | --- | --- |
| 1 | 1 | 5 | 원문 리뷰 텍스트 | 높은순 1번째 |
| 1 | 2 | 5 | 원문 리뷰 텍스트 | 높은순 2번째 |
| ⋯ | ⋯ | ⋯ | ⋯ | ⋯ |
| 1 | 101 | 1 | 원문 리뷰 텍스트 | 낮은순 1번째 |
| 1 | 102 | 2 | 원문 리뷰 텍스트 | 낮은순 2번째 |

제품별 시트로 수집된 원본 데이터를 국가 단위로 통합하여 **리뷰 1건 = 1행** 구조로 정리하였다.

## 8. ⚠️ 데이터 수집 시 고려사항

- 4개국 모두 **제품 수와 제품별 리뷰 수를 동일하게 설정**하여 국가 간 표본 규모를 맞췄다.
- 고평점 리뷰와 저평점 리뷰를 각각 100건씩 의도적으로 수집했기 때문에, 해당 데이터는 플랫폼 전체의 자연발생 별점 분포를 그대로 반영하는 표본은 아니다.
- 플랫폼별 UI·HTML 구조가 달라 크롤링 구현에는 차이가 있으나, **분석 대상·제품 수·리뷰 수집 기준·최종 데이터 구조는 동일하게 유지**하였다.
